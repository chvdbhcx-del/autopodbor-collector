# Сборщик для @autosearchcorapt_bot

Раз в час (GitHub Actions, `collect.yml`):
1. обходит площадки, которые бот сам открыть не может (список `sites` в `config.yaml`, модули `src/sources/`);
2. читает новые посты Telegram-каналов продавцов (`channels`), склеивает альбомы одной машины;
3. отправляет всё боту JSON-пакетом от отдельного Telegram-аккаунта и просит бот обновить подписки (`#refresh`).

Состояние (что уже отправлено) хранится в ветке `state` (`state.json`). В нём только отпечатки объявлений
и хеши описаний; записи машин, не встречавшихся на площадках 45 дней, удаляются. Битый `state.json` останавливает
запуск с ошибкой (иначе сборщик разослал бы всю базу заново).

«Ещё продаются»: каждый проход отправляет боту uid всех известных ему машин, найденных в списках площадок
(не только изменившихся). Раз в сутки на модель сборщик листает ещё до 10 страниц списка, пока на них
встречаются уже отправленные машины, — так бот не скрывает живые объявления, ушедшие с первой страницы.

Каналы: отметка «прочитано» двигается только после того, как объявления и фото канала дошли до бота.
При FloodWait дольше 2 минут отправка откладывается до следующего запуска, а запуск помечается красным.

## Секреты (Settings → Secrets and variables → Actions)
| Имя | Что это |
|---|---|
| `TG_API_ID`, `TG_API_HASH` | ключи приложения с https://my.telegram.org → API development tools (для запасного аккаунта) |
| `TG_SESSION` | строка сессии, её печатает `npm run login` |
| `GROQ_API_KEY` или `ANTHROPIC_API_KEY` | разбор постов каналов и перевод описаний (без ключа каналы пропускаются) |
| `SESSION_KEY` | рекомендуется: случайная строка (например, `openssl rand -base64 32`), ключ шифрования `session.enc` в ветке `state`. Без него ключом служит `TG_API_HASH`; после добавления сборщик сам перешифрует файл |
| `WG_CONF` | необязательно: WireGuard-конфиг; включается переменной `USE_WG=1`. Если туннель не поднялся, запуск идёт без VPN |

После первого запуска отправьте боту с админского аккаунта `/ingest <id аккаунта сборщика>` (id печатается в логе).
